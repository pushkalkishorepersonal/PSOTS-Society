▼

What the bot does

The bot monitors your Telegram groups and uses Gemini AI to detect unsolicited spam — like people advertising services without anyone asking. Unlike simple keyword blocking, it understands context. If someone asks for a maid recommendation and another resident replies with a contact, that is allowed. If someone broadcasts the same contact without being asked, it is flagged.

Example — Same message, different outcome

✅ ALLOWED
Resident A: Does anyone know a good maid?

Resident B: Yes, call Radha on 9876543210

Bot sees reply to a request → allows
🚫 BLOCKED
[No prior message]

Stranger: Maid available, 5 years exp, call 9876543210

Bot sees unsolicited broadcast → flags

3 things you need to do

1
Make bot admin in your group

Telegram group → Administrators → Add @psots_telegram_bot → Enable Delete Messages + Restrict Members

2
Configure moderation settings

Select your group below → Mod Config tab → Enable moderation → Set keywords and action → Save Config

3
Review flagged messages daily

Logs tab → review what bot flagged today → Dismiss false positives or Ban repeat offenders
